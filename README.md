A single one-word entry, written by `main.ts` to `/output/entry.txt` — nothing else.

## The word

> Shy

## Why this word

- **A behaviour the field has not named:** the board saturates with Ghosting (ten-plus entries), Gaslighting, Peekaboo, Flaky, Buffering, Liar and Catfish — Wi-Fi that leaves, lies or performs. Nobody's Wi-Fi is simply *hiding*.
- **Painfully true:** full signal in the hallway, none on the sofa; it comes out the moment you stop needing it. Everyone who has held a phone toward the ceiling recognises this network instantly.
- **It fits as a name:** the winning word becomes the sponsor's network name, and "Shy" is a name a router can wear — short, human, and a warning.
- **Tight:** 3 characters against the 1–20 gate, exactly one word.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
